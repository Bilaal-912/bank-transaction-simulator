# Bank Transaction Simulator

A multi-threaded console-based banking system built in pure Java, simulating concurrent deposits and withdrawals across shared accounts to demonstrate thread safety, synchronization, and safe concurrent collection use.

## Features (planned)
- Create accounts with a starting balance
- Simulate multiple threads performing deposits/withdrawals on the same account concurrently
- Demonstrate race conditions when synchronization is missing, then fix them
- Thread-safe balance updates using synchronization / locks

## Tech Stack
- Java (no external frameworks)
- Concurrency: Threads, `ExecutorService`, `synchronized`, Locks
- Collections API
